# Archived multi-modal documentation

These documents describe the legacy multi-modal implementation, which is
quarantined under `_superseded/`. They are retained for historical context only.

Performance, uptime, cache-hit, and cost numbers in this directory are **not
evidence for the active gateway** and must not be quoted as current results.
See `data/evidence/` and `benchmarks/results/README.md` for reproducible active
measurements.
